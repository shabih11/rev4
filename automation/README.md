# Windsor → Firestore

المصدر Google My Business عبر Windsor، والوجهة `iamspec / apps/rev4`.
تعمل `.github/workflows/windsor-sync.yml` يوميًا الساعة 22:00 بتوقيت الرياض؛ قد يتأخر تشغيل GitHub المجدول.
يمكن تشغيلها يدويًا من Actions مع تحديد تاريخ البداية والنهاية للمراجعة التاريخية.

## التفعيل

أضف مفتاح Windsor إلى **Actions secret** باسم `WINDSOR_API_KEY` في مستودع `shabih11/rev4`.
لا تضع المفتاح في ملفات المصدر أو متغيرات `VITE_*` أو سجلات التنفيذ.
هوية Google معدّة باستخدام OIDC: المزود `rev4-github/providers/github` وحساب الخدمة `rev4-windsor-sync` في `iamspec`.
المزود مقيد بالمعرّفين الرقميين للمالك والمستودع وملف المزامنة على `main`.
الدور المخصص `rev4WindsorSync` يتيح قراءة وإنشاء وتحديث مستندات Firestore دون الحذف؛ IAM يعمل على مستوى قاعدة البيانات، وليس مسار المستند.
لا تستخدم مفاتيح JSON دائمة ولا تغيّر قواعد Firestore لتشغيل المزامنة.

## تقليل الاستهلاك

- طلب مصدر مركزي واحد في اليوم بدل الطلب مع كل زيارة أو كل دقيقة.
- القراءة العادية للتطبيق من Firestore؛ لا يتصل مستخدمو التطبيق بالمصدر تلقائيًا.
- النافذة الافتراضية تشمل الشهر السابق والحالي لالتقاط التعديلات الحديثة. التعديلات الأقدم تحتاج تشغيلًا يدويًا بنطاق أوسع.
- بصمة لكل تقييم في نقاط تحقق شهرية خاصة؛ النسخة غير المتغيرة تقرأ مستند تحقق واحدًا لكل شهر ولا تكتب شيئًا.
- تُحدّث الحقول المتغيرة فقط، مع الحفاظ على تعيينات الموظفات والشفتات الموجودة.
- تُحدّث `reviews` و`reviewSignals` وأحداث `timeline` معًا في دفعات محدودة مع شروط إصدار تمنع تجاوز تعديل متزامن.
- فشل المصدر أو رد فارغ لا يحذف سجلات. نقاط التحقق تُكتب بعد نجاح الدفعات؛ إعادة المحاولة آمنة.
- تُطابق الفروع بمعرّفات المواقع الستة، ويُربط التقييم الجديد بالشفت الأقرب الذي يغطي وقته، بما فيه ما بعد منتصف الليل.

يتوقف التشغيل عند رد غير مكتمل أو موقع غير معروف أو تضارب إصدار؛ راجع فشل Actions ثم أعد التشغيل.
الملخص في السجل يعرض الأعداد فقط. لا تُرفع نسخ التقييمات أو مفاتيحها ضمن artifacts.
تحتاج المزامنة اشتراك Windsor صالحًا؛ وتيرة تحديث المصدر تعتمد على الخطة.

المراجع: [Windsor API](https://windsor.ai/api-documentation/)، [تسعير Firestore](https://firebase.google.com/docs/firestore/pricing)، [Google OIDC](https://github.com/google-github-actions/auth).

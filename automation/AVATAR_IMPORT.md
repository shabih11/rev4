# رفع الأفاتارات بالكود

الأمر `npm run avatars:import` يرفع ملفات WebP مباشرة إلى مخزن `avatar-store` ويسجلها عبر دوال التطبيق القائمة. لا يحتاج زر رفع الصور أو نشر نسخة جديدة من الواجهة أو صلاحيات `service_role`.

## فحص المجموعة الحالية دون رفع

من جذر التطبيق:

```sh
npm run avatars:import -- \
  --manifest ../saudi-modern-avatar-store-upload/upload-plan.json \
  --collection 0f46e546-ae29-47f9-8f81-1ea1058b9a6e \
  --dry-run
```

أزل `--dry-run` لتنفيذ الرفع بعد تجهيز تسجيل الدخول. يتحقق الأمر من جميع الصور وبصماتها قبل أي كتابة. المجموعة المشار إليها هي «الذوق السعودي الحديث» المخفية؛ تُحفظ الصور الخمس الموجودة، وتُرفع الصور الناقصة.

## تسجيل الدخول

استخدم متغير `REV4_ADMIN_ACCESS_TOKEN` لجلسة إدارة صالحة، أو المتغيرين `REV4_ADMIN_EMAIL` و`REV4_ADMIN_PASSWORD` لتسجيل الدخول المعتاد. يتحقق الأمر من المستخدم عبر خدمة Auth ثم من دور الحساب عبر `get_my_account`؛ يتوقف عند عدم وجود صلاحية الإدارة.

لإدخال بيانات الإدارة من الطرفية دون كتابتها في سجل الأوامر (zsh على macOS):

```sh
read 'REV4_ADMIN_EMAIL?بريد حساب الإدارة: '
read -s 'REV4_ADMIN_PASSWORD?كلمة المرور: '
export REV4_ADMIN_EMAIL REV4_ADMIN_PASSWORD
npm run avatars:import -- \
  --manifest ../saudi-modern-avatar-store-upload/upload-plan.json \
  --collection 0f46e546-ae29-47f9-8f81-1ea1058b9a6e
unset REV4_ADMIN_EMAIL REV4_ADMIN_PASSWORD
```

لا تحفظ بيانات الدخول في المستودع ولا ترسلها في المحادثة. لا تُحفظ جلسة جديدة على القرص، ويُسجّل الخروج من جلسة الأمر بعد الانتهاء. يمكن ضبط `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` لاستهداف مشروع آخر عمدًا؛ الافتراضي هو مشروع التطبيق الحالي.

## صيغة ملف الاستيراد

ملف JSON بجوار الصور، مثل:

```json
{
  "collection_name": "اسم المجموعة",
  "draft_price": 5,
  "collection_enabled": false,
  "variants_enabled": false,
  "variants": [
    {
      "name": "01 · اسم الشكل",
      "file": "avatar-01.webp",
      "sha256": "بصمة SHA-256 الفعلية للملف: 64 خانة ست عشرية"
    }
  ]
}
```

الصور ثابتة، حتى 5 ميغابايت و4096 بكسل لكل بُعد. تُرفض الأسماء المتكررة والمسارات الخارجة من مجلد الاستيراد، بما فيها الروابط الرمزية. يجب أن تطابق بصمة كل ملف القيمة المحددة.

## الاستئناف والإخفاء

- تُنشأ المجموعات الجديدة مع `enabled=false`. تُرفض المجموعة المنشورة بدل تعديل حالة عرضها تلقائيًا.
- تُطابق الأشكال الموجودة بالاسم داخل المجموعة، وتُحفظ صورها دون استبدال، ويُعطّل عرضها للبيع. تُرفض الأشكال المُقتناة أو الأسماء المكررة.
- للملفات الجديدة مسارات ثابتة مشتقة من المجموعة والاسم والبصمة، مع `upsert=false`. إذا انقطع التسجيل بعد الرفع، يعيد الأمر استخدام الملف نفسه بعد مطابقة بصمته.
- لا يحذف الأمر ملفات أو مشتريات، ولا يغيّر السعر الحالي أو إعداد تفعيل متجر الموظفات.
- في النهاية يُتحقق من بقاء المجموعة وكل الأشكال المستوردة مخفية، ومن إمكانية قراءة صورها من المخزن. لا يوجد خيار نشر ضمن هذا الأمر؛ النشر لاحقًا من إعدادات الإدارة.
